# Repository scope

This repository contains the Battle of the Old West game source code,
Unreal project configuration, card data, automated tests, authoring and build
scripts and historical research.

Generated Linux packages, Unreal caches, local reconnect profiles, test
recordings, and credentials are excluded. Existing local files are retained.

The large Blender/FBX/texture sources under `art/` and Unreal assets under
`game/OldWest/Content/` (except `Data/`) remain local and are not backed up by
this code-only repository. A fresh clone can build the portable rules/AI tests. Building the complete Unreal game also requires the
existing art assets and Unreal installation. Authoring scripts do not replace
all imported source assets.

The Unreal project directory, module and target keep their original internal
names (`game/OldWest`, `OldWestGame`); players never see them, and renaming
them is a tracked backlog item because it touches every build and test script.

Run the portable tests from the repository root:

```sh
cmake -S game/tests/core -B /tmp/old-west-core-build -DCMAKE_BUILD_TYPE=Release
cmake --build /tmp/old-west-core-build -j2
ctest --test-dir /tmp/old-west-core-build --output-on-failure
```

See `game/README.md` for development instructions and `game/THIRD_PARTY_NOTICES.md`
for third-party components. Local generated validation reports referenced by
other documents can be regenerated by the scripts; they are excluded here.
