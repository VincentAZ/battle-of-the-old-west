# Build T playtest brief

Status: awaiting the user's test and feedback.

Build T includes the current accepted character work plus the gameplay,
portrait, camera and sound changes. The connected-shirt experiments are not
included; visible clothing defects and fall stability still need work.

Start from the repository with `scripts/launch_battle_of_the_old_west.sh`, which follows
`dist/current`, or use Build T's bundled launcher. Read its `REVIEW_NOTES.md`
for the checks performed on this exact package.

Play one complete solo match against Normal AI. Try the controls without
coaching, let several cinematics finish, try Skip, and notice camera return.
Listen at a comfortable volume and try master mute once. Try a rematch.

Send feedback in chat, including the card/action where possible:

- What was confusing?
- What visual, movement or sound distracted you?
- Did camera movement, pacing and difficulty feel right?
- What one change would most improve the next match?

Local two-player feedback can follow when another player is available. Record
only what was actually played. Internet, Windows and production deployment
remain deferred.
