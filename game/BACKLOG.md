# Deferred release work

The active priority is game polish: art, effects, sound and human
playtesting. The following release buckets are shelved at the user's request
on 8 September 2026. They are not prerequisites for local polish work.

- **Production packaging:** Shipping configuration, production distribution and
  validation of the release artifact. Development builds remain available for
  reviewing polish changes.
- **Internet multiplayer validation:** second-computer/network coverage,
  Internet/NAT traversal and the hosting/matchmaking decisions required for
  broad distribution. Local playtesting remains in the active polish scope.
- **Windows support:** finish packaging and validate on Windows hardware.
- **Build reproducibility:** back up the complete source art and Unreal assets,
  then prove a full build from a clean checkout and restored assets.
- **Browser deployment:** decide between Pixel Streaming with GPU hosting and a
  browser implementation; implement and validate the chosen route. A Vercel
  website alone cannot run the current native game.

Resume these buckets when requested; their earlier release-checklist evidence
and limitations remain applicable.
